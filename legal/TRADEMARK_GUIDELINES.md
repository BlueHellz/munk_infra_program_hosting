# MUNKEE STUDIO - PERMITTED BRANDING & TRADEMARK GUIDELINES

## 1. MUNKEE STUDIO Identity
- MUNKEE STUDIO branding applies to the window container frame, startup splash presentation, top navigation status bar, and workspace themes.
- Primary Brand Colors:
  - MUNK Electric Blue: `#0066FF`
  - Dark Charcoal: `#181A1F`
  - Surface Dark: `#20232A`

## 2. Upstream Application Trademark Respect
- Original application names and trademarks (e.g., Audacity, Penpot, MiniPaint, Darktable, Shotcut) are respected.
- MUNKEE STUDIO does NOT claim ownership of upstream trademarks.
- Upstream software names are cited as technology providers in application legal notices and manifests.
- MUNKEE STUDIO user-facing names (Photo & Raster, UI & Prototype, Vector & Logo, 2D Animation, Music & DAW, Texture Painter, PBR Materials, Video Timeline, Motion & VFX, RAW & Color, Print & Layout) describe studio function categories.

## 3. Permitted UI Modifications
- Modifying UI container styling, top window frame, title bar color, font family (Inter), primary accent colors.
- Adding MUNKEE STUDIO header bar and legal attribution footer.
- **PROHIBITED**: Removing upstream copyright notices, hiding license agreements, or modifying editing algorithms in a way that obscures software origins.
